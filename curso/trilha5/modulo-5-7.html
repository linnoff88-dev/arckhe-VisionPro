1 Configurações de Exportaçêo

Cada plataforma tem requisitos específicos. Vamos exportar versões otimizadas para cada destino.

👑 Master (Arquivo Principal)

OBRIGATÓRIO

Configurações:

  • • Codec: ProRes 422 ou DNxHR
  • • Resoluçêo: 1920x1080
  • • Frame rate: 24fps
  • • Áudio: PCM 48kHz 24-bit

Por que manter:

  • • Qualidade máxima preservada
  • • Base para futuras versões
  • • Re-exports sem perda

📺 YouTube / Vimeo

~60-80 MB
  • • Codec: H.264 (mais compatível)
  • • Resoluçêo: 1920x1080
  • • Bitrate: 15-20 Mbps
  • • Áudio: AAC 320kbps
  • • Frame rate: 24fps
  • • Container: MP4
  • • Profile: High
  • • Level: 4.2

📱 Instagram Feed / Reels

~30-50 MB

Feed (Quadrado)

  • • Resoluçêo: 1080x1080
  • • Aspect: 1:1
  • • Bitrate: 10 Mbps

Reels (Vertical)

  • • Resoluçêo: 1080x1920
  • • Aspect: 9:16
  • • Bitrate: 10 Mbps

⏳ Stories (15s version)

~10-15 MB
  • • Resoluçêo: 1080x1920 (9:16)
  • • Duraçêo: 15 segundos (versêo condensada)
  • • Bitrate: 8 Mbps
  • • Incluir legenda (muitos assistem sem som)
PROMPT: CONFIGURAÇÕES DE EXPORT DAVINCI 
Forneça as configurações exatas de export no DaVinci Resolve Deliver page para cada formato.

FORMATOS NECESSÁRIOS:
1. Master ProRes (arquivo principal)
2. YouTube H.264 1080p
3. Instagram Feed 1:1
4. Instagram Reels 9:16
5. Stories 15s 9:16

PARA CADA FORMATO, ESPECIFIQUE:
- Preset base (se houver)
- Video Codec e configurações
- Resolution override
- Frame rate
- Quality/Bitrate settings
- Audio Codec e bitrate
- File extension
- Naming convention sugerida

INCLUIR TAMBÉM:
- Como salvar como Custom Export Preset para reuso
- Ordem recomendada de rendering (queue)
- Estimativa de tempo de render
- Tamanho aproximado de arquivo
