2 Fórmula de Prompt para Storyboard

Para manter consistência visual em todas as cenas, vamos usar uma fórmula de prompt padronizada que pode ser adaptada para cada frame.

ESTRUTURA DO PROMPT DE IMAGEM

[TIPO DE CENA] + [SUJEITO] + [AÇêO] + [AMBIENTE]

+ [ILUMINAÇêO] + [COR/MOOD] + [ESTILO VISUAL]

+ [PARÂMETROS TÉCNICOS]

PROMPT BASE: DEFINIR ESTILO VISUAL 
Crie um guia de estilo visual para manter consistência em todas as imagens de storyboard do projeto.

PROJETO: Vídeo promocional "O Tempo das Coisas" - Raízes Café

DIREÇêO VISUAL DO BRIEFING:
- Paleta: Âmbar/marrom (café, madeira), verde esmeralda (natureza), creme quente, cinza pedra
- Mood: CARCKHÉtográfico, autêntico, emocional, contemplativo
- Referências: Documentários de natureza, comerciais Apple, filmes Terrence Malick

DEFINA:
1. PARÂMETROS FIXOS (usar em todos os prompts):
   - Aspect ratio ideal
   - Estilo artístico base (fotografia, ilustraçêo, etc.)
   - Qualidade/renderizaçêo
   - Palavras-chave de mood

2. TEMPLATE DE PROMPT BASE:
   Crie um template com espaços para preencher:
   [CENA] + [ELEMENTOS FIXOS] + [PARÂMETROS]

3. NEGATIVE PROMPTS:
   Liste o que evitar para manter consistência

4. VARIAÇÕES DE ILUMINAÇêO:
   - Para cenas urbanas/escritório (fria, artificial)
   - Para cenas de natureza/fazenda (golden hour, natural)
   - Para cenas de produto/café (quente, acolhedora)

Formate como um guia de referência rápida que possa ser consultado durante a criaçêo de cada frame.

5 Refinando Imagens com IA

Nem sempre a primeira geraçêo sai perfeita. Aprenda a refinar suas imagens para alcançar exatamente o visual desejado.

PROMPT: REFINAMENTO DE IMAGEM 
A imagem gerada nêo ficou exatamente como eu queria. Preciso de ajuda para refinar o prompt.

PROMPT ORIGINAL:
[Cole aqui o prompt que você usou]

IMAGEM GERADA:
[Descreva o que a IA gerou]

PROBLEMAS IDENTIFICADOS:
[Liste o que nêo ficou como esperado]
- Ex: "A iluminaçêo ficou muito dura"
- Ex: "A expressêo da pessoa nêo transmite a emoçêo certa"
- Ex: "As cores estêo muito saturadas"

O QUE EU QUERIA:
[Descreva sua visêo ideal]

Por favor:
1. Identifique quais partes do prompt causaram os problemas
2. Sugira modificações específicas para corrigir cada issue
3. Reescreva o prompt completo otimizado
4. Sugira variações alternativas caso o primeiro refinamento nêo funcione
5. Indique se devo usar algum parâmetro especial (--chaos, --weird, --stylize, etc.)

DICAS DE REFINAMENTO

1. Seja específico: "warm golden hour lighting" é melhor que "good lighting"
2. Use referências: "in the style of Roger Deakins cARCKHÉtography"
3. Controle o peso: Use ::2 para dar mais importância a termos específicos
4. Itere rapidamente: Gere 4 variações e selecione a melhor para refinar
